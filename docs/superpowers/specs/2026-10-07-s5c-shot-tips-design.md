# S5c 镜头拍摄提示（设计）

日期：2026-10-07。版本：S5c（S5 下的中版本，npm 0.12.0）。路线图原计划的「S3b 镜头拍摄提示」：每场一次，给每个镜头难度、器材和 2–3 条实拍提示，镜头改动后提示过期，可以印进拍摄单。

## 1 目标

学生剧组拿到镜头表后，常问的是「这个镜头用手机怎么拍」「要带什么」。拍摄提示回答这两个问题，只作参考，不改镜头。

- 每个镜头有：
  - **难度**：易、中、难；
  - **器材**：从固定词表里选；
  - **实拍提示**：2–3 条，手机或入门设备能做到，每条最多 60 字；
  - **常见失误**：1 条，最多 60 字。
- **不用 key 也有**：难度和器材先按镜头字段估一版，标「按镜头字段估计」。
- **AI 提示**：按场生成，每场一个任务，最多外发 3 次，计入每日上限，演示模式可回放。
- **过期**：镜头改过以后，AI 提示标为「镜头改过，提示可能过时」，可以重新生成这一场。
- **显示位置**：
  - 镜头编辑器里新增「拍摄提示」一组；
  - 镜头表每行带难度标签，只标「难」，不多占地方；
  - 拍摄单打印预览可以勾「附拍摄提示」，按拍摄顺序印在表后。

不做：
- 按器材清单自动生成器材资源（以后可接 S5a 的器材）；
- 逐镜头单独调用；
- 视频示例。

## 2 契约（lead，`packages/contracts/src/tips.ts`）

- `ShotDifficulty = ['easy', 'medium', 'hard']`。
- `ShotGear` 共 10 种：
  - `tripod` 三脚架；
  - `gimbal` 稳定器；
  - `slider` 滑轨；
  - `external_mic` 外接麦；
  - `boom` 收音杆；
  - `light` 补光灯；
  - `reflector` 反光板；
  - `phone_lens` 手机外接镜头（广角、微距、长焦）；
  - `drone` 无人机；
  - `car_mount` 车载支架。
- 常量：`TIP_TEXT_MAX = 60`、`TIPS_MIN = 2`、`TIPS_MAX = 3`、`TIP_SHOTS_MAX = 40`。
- `ShotTipsOutput`（模型输出）：`{ shots: [{ ref, difficulty, gear: ShotGear[], tips: string[], mistake }] }`，其中 `ref` 是 s1、s2 …。
- `ShotTip`（读到的视图）：
  - `shot_id`、`difficulty`、`gear`、`tips`、`mistake`；
  - `source`：`'ai'` 或 `'rule'`；规则估计的 tips 为空、mistake 为 null；
  - `stale`；
  - `created_at`、`actor`、`prompt_version`，规则估计时三者为 null。
- `ShotTipsView`：`{ tips: ShotTip[] }`，每个未归档的镜头一条。
- 路由：
  - `GET /api/v1/tips`：`getShotTips`；
  - `POST /api/v1/scenes/:id/tips`：`startShotTips`，返回 `JobAccepted`。
- `JobKind` 新增 `shot_tips`。
- 项目库迁移 009 `shot_tip`：
  - 每个镜头一行，镜头删除时级联删除；
  - 列：`basis_hash`（生成时镜头的 content_hash）、`difficulty`、`gear_json`、`tips_json`、`mistake`、`job_id`、`model`、`prompt_version`、`actor_id`、`created_at`。
  - `PROJECT_SCHEMA_VERSION = 9`。

## 3 规则估计（core `shots/tips.ts`，纯函数）

`ruleTips(fields, time)` 返回 `{ difficulty, gear }`。

- **器材**，按顺序去重：

  | 条件 | 器材 |
  |---|---|
  | 运动是 static | 三脚架 |
  | track、handheld、orbit、crane | 稳定器 |
  | push_in、pull_out、dolly_zoom | 滑轨 |
  | aerial | 无人机 |
  | vehicle | 车载支架 |
  | 有台词 | 外接麦 |
  | 有台词且画面里 2 人以上 | 收音杆 |
  | 夜景 | 补光灯 |
  | 白天的 CU、MCU、ECU 且有人 | 反光板 |
  | INSERT 或 ECU | 手机外接镜头（微距） |

- **难度**：
  - **难**：`set_piece`，或运动是 aerial、vehicle、dolly_zoom、orbit、crane，或画面里 4 人以上；
  - **中**：运动是 track、handheld、push_in、pull_out、pan、tilt，或主体在动，或夜景，或 2 人以上的对白；
  - **易**：其余。
- 时段沿用 S5b 的 `timeOfDay`，CONTINUOUS 的场次由服务端按上一场换算。

## 4 AI（prompt `tips-v1`）

- **输入**：
  - 场次标题和时段；
  - 本场未归档的镜头按顺序编号 s1…，每个给出镜号、景别、角度、焦段或镜头类型、运动、人物数和姿势、道具、环境、是否重点段落、动作（40 字）、有无台词、拍法说明；
  - 规则估计的难度和器材，作为参考。
- **系统提示（中文）**：
  - 面向用手机、入门相机和稳定器的学生剧组；
  - 器材只能从词表里选；
  - 每个镜头恰好一项；
  - 提示要具体可做，比如机位高度、走位标记、对焦锁定、收音距离、补光方向；
  - 不写人名、片名，不声称某部电影这样拍。
- **归一化**：中文的难度和器材写法（易、简单、难；三脚架、稳定器、领夹麦……）映射到枚举；空字符串当作没有。
- **校验**（进修复轮）：
  - ref 必须对应本场镜头，不重复、不遗漏；
  - tips 2–3 条，每条非空、不超过 60 字；
  - mistake 非空、不超过 60 字；
  - 器材在词表内；
  - 片名和导演声称沿用 `flagFilmClaims`。
- **重试用完后**：合格的条目照常保存，不合格的略去，并注明略去了几条；一条都不合格时任务失败，不覆盖旧提示。
- **写入**：任务提交时，按每条对应镜头在**发送时**的 content_hash 存为 `basis_hash`，覆盖该镜头的旧提示（upsert）。发送之后镜头又被改过的，读到时就是 stale。
- **幂等键**：`shot_tips:<scene_id>:<各镜头 content_hash 的哈希>`。同样的镜头不会重复排队。
- **演示**：回放键 `tipsReplayKey(heading, codes)` 是场次标题加镜号的哈希；`fixtures/replay/01-bookshop.tips-v1.scene-1.json` 和 `scene-2.json` 是手写的原创内容。镜头改动后回放找不到录音，会明确报错。

## 5 前端

- 标签：
  - 难度：易、中、难；
  - 器材：中文名，见 §2。
- **镜头编辑器**：已保存的镜头有「拍摄提示」组，依次显示：
  - 难度标签，器材标签；
  - 来源：「AI · 阿杰 10:32」，或「按镜头字段估计」；
  - 实拍提示（有序列表）；
  - 「常见失误：……」；
  - 过期时显示提示条和「重新生成本场」；
  - 按钮「AI 生成本场拍摄提示」。按下先确认：发往哪个服务、本场 N 个镜头、最多外发 3 次、计入每日上限；演示模式写「回放录好的示例」。
  - 任务进行中显示进度；失败时显示原因。
- **镜头表**：每行在镜号旁加难度标签，只在难度为「难」时显示。
- **拍摄单打印预览**：有勾选项「附拍摄提示」，默认不勾。勾上后，按拍摄单里镜头出现的顺序印出：镜号、难度、器材、提示、常见失误。
- 任务名「拍摄提示」：写进任务列表和用量明细。
- 协作：
  - `shot_tips` 任务结束时刷新 jobs 和 shots 区域；
  - tips 的查询根归到 shots 区域；
  - `startShotTips` 路由归到 jobs 区域。

## 6 测试

- **core**：
  - 规则估计覆盖每种运动、台词、夜景、人数和插入镜头；
  - 归一化；
  - 校验：未知、重复、缺失的 ref，条数，长度，器材，片名声称；
  - 提示词快照。
- **server**：
  - 用 FakeChat 跑一场：存入、upsert、过期（改镜头后为 stale）；
  - 部分合格时只存合格的；
  - 全不合格时任务失败、旧提示保留；
  - 需要 key 和每日上限；
  - 演示回放；
  - 归档的镜头不出现；
  - 迁移 009。
- **web**：标签、来源文字、过期判断、打印附表的排序。
- **e2e**（演示模式）：
  - 打开镜头 001，看到规则估计；
  - 生成本场提示，AI 提示出现；
  - 改镜头运动，出现过期提示；
  - 拍摄单勾「附拍摄提示」，印出提示。
