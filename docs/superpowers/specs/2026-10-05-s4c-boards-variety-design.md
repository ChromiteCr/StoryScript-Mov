# S4c 分镜画面与镜头变化（设计）

日期：2026-10-05。版本：S4c（S4 下的中版本）。

## 0 反馈与证据

同学的反馈：分镜图画得差，镜头形式太单一。

- **线上「绳索」组**（只读统计，共 12 个镜头）：
  - 角度：9 个平视；运动：9 个固定机位；景别：7 个近景（MCU）。
  - 镜头：10 个标准镜头；技法：11 个正反打。
  - 人物：12 个镜头全部没有人物运动，姿势几乎都是「站」，也没有任何拍法说明。
  - 原因：默认的拆镜请求走 breakdown-v1，提示词只说"宁可少而准"，没有任何关于变化的要求。
- **12 个标准镜头的铅笔稿**：
  - 人物是没有五官的深灰人台，中景人物整块是灰色，脸和衣服分不出来。
  - 室内是空盒子，街道是没有窗户的方块楼，开阔地只有一条地平线。
  - 单人镜头默认放在画面正中、面向镜头，所以每个近景看起来都一样。
  - 这是 PLAN.md「人物画成实心剪影」的直接结果。S4c 修改这条画风规则。

## 1 目标

1. 人物像人：
   - 有脸（眉、眼、鼻、嘴、耳）和发型；
   - 衣服分上下装和深浅，鞋子画深色；
   - 同一个角色在不同镜头里穿着和发型一致，不同角色一眼能分开；
   - 同一个姿势有几种手势变化（插兜、抱臂、叉腰、说话的手势……），两个人不会像复制出来的。
2. 新增姿势：躺、跪、伸手、打电话。
3. 场景有内容：
   - 室内有门窗、踢脚线和家具；
   - 教室有黑板和成排的课桌；
   - 走廊又长又窄，两侧有门；
   - 街道的楼有窗，路边有路灯和树；
   - 野外有树和山脊。
   - 新增道具：床、沙发、书架、灯、树、手机、杯子、书、包。
4. 构图有变化：单人镜头按视线留白放在三分线上，正反打自动左右交替。
5. AI 拆镜不再千篇一律：
   - 新提示词 breakdown-v3，要求景别、角度、运动、人物动作有层次；
   - 新增确定性的「镜头变化检查」；
   - 检查结果很单一时，在外发次数上限内再问一轮；
   - 润色新增「丰富变化」方式。
6. 已有项目也能用上新画法：
   - 人物画法在渲染时生效，所有分镜自动变好看；
   - 新的布景只在重新排版时出现，所以分镜页提供「用新画法重排（不动手改过的）」。

非目标：
- 不改 BoardSpec 的版本号；
- 不改 AI 重绘；
- 不引入彩色；
- 不画真人或真实影片中的角色。

## 2 契约（lead，已完成）

- `Pose` 新增 `lie | kneel | reach | phone`。
- `PropKind` 新增 `bed | sofa | shelf | lamp | tree | phone | cup | book | bag`。
- `EnvKind` 新增 `nature | corridor | classroom`。
- `BoardSubject.gesture`：0–15 的整数，可选可空。不填时由 `seed` 和 subject id 决定，用 `% 变体数` 取模。
- `PolishMode` 新增 `vary`。
- 新路由：`relayoutBoards`，POST `/api/v1/boards/relayout`，输入 `{scene_id}`，返回 `{relaid, kept_edited, already_current}`。协作动态里归入 boards 区域。

## 3 不变量

- 确定性：同一份 spec 输出逐字节一致；改一个元素不影响其他元素的随机量。随机量一律用 `rngFor(seed, key)`。
- **`structureHash(spec)` 对已有 spec 保持字节一致**，否则所有已采用的 AI 重绘都会被标成"结构已变"。
  - 画法升级不能改变这个哈希的输入。冻结旧的 look 和版本字段，作为哈希专用常量。
  - 新增 `PICTURE_VERSION`，用于前端图片缓存的 key。
- SVG 只用表现属性；文本要转义；只用灰色。
- 代码、提示词、UI 和测试数据里不出现真实人名、片名和 IMAX（CLEANROOM）。
- core 保持纯函数。
- 画风指标 L1–L7 仍对 12 个标准镜头断言。某条阈值和新画风确实矛盾时，带渲染证据提出修改，由 lead 决定。
- 性能：单格 pencil 生成 < 150 ms（现在最大 15 ms），1840 px PNG < 1.5 s。

## 4 F 线：人物

文件：
- puppets.ts，以及可选的新文件 puppet-style.ts；
- camera.ts：躺、跪的取景；
- scene.ts 的 projectSubject；
- pencil-plan.ts 的人物区域；
- pencil.ts 的人物部分和 structureHash；
- render.ts 的 subjectSvg（结构图）。

- **新姿势关节表**：每个都写 FRONT 和 SIDE 两张，沿用现有的三维约定。
  - lie：沿 F 轴平躺，头朝 +F，高度约 0.05–0.2；
  - kneel：单膝或双膝着地；
  - reach：一臂前伸到肩高；
  - phone：一手持机贴耳。
  - poseTopY、取景和人物框要对躺姿正确：躺着时按身长取景，不能只看头顶高度。
- **手势变体**：用 `gesturesFor(pose)` 列出覆盖手臂和头部关节的变体。
  - stand 至少 5 种：自然下垂、插兜、抱臂、单手叉腰、说话手势；
  - sit 至少 3 种；walk 至少 2 种；其余姿势至少 1 种；
  - 变体之间可以有小幅的头部偏转或歪头。
- **角色造型**：由 `entity_id ?? label` 的哈希决定，所以同一角色每格一致。
  - 发型从 6 种里取，dress 剪影偏向长发、马尾或发髻；
  - 上衣和下装各取浅、中、深，两者不能相同；
  - coat 和 dress 剪影保留。
- **部件材质**：PuppetPart 增加 `material: 'skin' | 'hair' | 'top' | 'bottom' | 'shoe'`。
  - 脸、脖子、手是 skin，头发是 hair，躯干和上臂、前臂是 top，腿、裙、外套下摆是 bottom，脚是 shoe。
- **细节线**：
  - 五官：正面和 3/4 侧画两只眼、眉、鼻、嘴；侧面画眼、鼻、嘴、耳；背面画发旋和耳。
  - 衣服：领口、袖口、腰线。
  - 人物在画面里够大时才画五官；小人只画发型块面和脸的明暗。
- **铅笔明暗**：区域色调 = 景深档色调 + 材质偏移，再夹到 0–3。
  - 偏移：皮肤 −1，头发 +1，上下装按造型取 −0.5、0 或 +0.5，鞋 +1。
  - 过肩前景人物保持近黑的剪影。
  - 中景主体整体亮于原来的 0.44 灰，脸是亮的。
  - L4（前景 < 中景 < 远景）保持成立。
- 结构图里人物也画出五官、发型和衣服线，用线稿，头发块用浅灰填充。
- 自查：至少 3 轮 `npm run look`，读 PNG（compare-pencil、crop、thumbs、puppets）看效果。

## 5 S 线：场景、道具与构图

文件：
- layout.ts；
- scene.ts 的 propParts 和 groundLines，以及新的 billboard 道具；
- render.ts 的 propSvg 和 topview；
- pencil-plan.ts 的道具阴影集合；
- 标准镜头文件，新增「多样性」样张。

- **新道具几何**：
  - bed、sofa、shelf、lamp、phone、cup、book、bag 用盒子组合加装饰线（床头板、枕头、书脊、屏幕、杯柄等）。
  - tree 用公告板式剪影：树冠是不规则的圆块，按受光分亮面和暗面，下面是树干。由 scene.ts 生成多边形面，复用道具的明暗和轮廓流程。
- **旧分镜也受益的建筑细节**：在 propParts 里按 id 加装饰线，只依赖 spec。
  - `env-` 墙：踢脚线、墙裙或护墙板线；
  - 楼：每层每开间画窗，一楼画门或店面。
- **新排版时生成的布景**：都是 `env-` 道具，确定性由 seed 决定，不遮挡主体，也不压住画面中心的人。
  - interior：后墙一扇窗或门（镜头没列出时），空的那一侧放一件家具（书架、灯或沙发）。
  - classroom：后墙黑板（墙上的薄板，加边框装饰）；人物身后和两侧摆两到三排课桌椅；侧墙开窗。
  - corridor：宽约 2.4 m 的长走廊，两侧墙上隔一段一扇门；地面的线一直收到灭点。
  - street：保留现有的楼，再加路灯、行道树和路缘。
  - nature：散布几棵树，不挡主体，也不在镜头轴线上；地平线上画山脊或树线（渲染时生成）。
  - open：地平线上画远处的低山或树线（渲染时生成）。
- **构图**：
  - single 模板没给 screen 时，按场景轴线（scene_sides）和朝向放在三分线上，朝向对手，视线一侧留白；只有一个人且没有轴线时才居中。
  - two_shot 和 establishing 有前景人物时制造纵深。
- **小道具摆放**：
  - 有桌子就放桌上；
  - 打电话的姿势，手机在手上（可以省略，只画姿势）；
  - 包放在人物脚边；
  - INSERT 镜头里作为主体。
- **topview**：新道具有俯视图示，树画成圆。
- RENDERER_VERSION 改为 `board-s4c`。

## 6 V 线：镜头变化（AI）

文件：
- core/shots/variety.ts（新）；
- prompt/breakdown.ts、prompt/polish.ts；
- shots/normalize.ts（新枚举的同义词）；
- server 的 adapters/llm/structured.ts、ai/jobs.ts、ai/polish-jobs.ts；
- scripts/eval-breakdown.ts（如需要）。

- **`analyzeVariety(shots)`**：纯函数，返回 `{ stats, issues, score, severe }`。issue 用 DraftIssue 的格式，level 为 warning，code 以 `VARIETY_` 开头：
  - `SIZE_RUN`：连续 3 个以上镜头景别、角度、运动都相同；
  - `SIZE_DOMINANT`：5 个以上镜头时，单一景别超过 60%；
  - `FEW_SIZES`：4 个以上镜头时，景别少于 3 种；
  - `NO_WIDE`：4 个以上镜头时，没有 EWS、WS、FS 或 MLS；
  - `ALL_EYE`：6 个以上镜头时，全是平视；
  - `MOSTLY_STATIC`：4 个以上镜头时，固定机位超过 70%；
  - `ALL_CENTER`：人物都在画中或没填位置；
  - `MOTION_UNSET`：单个镜头的 action 写了走、跑、追、冲、进、出、离开、转身等，但姿势是站且没有人物运动。
  - `severe` 由明确的规则决定，在测试里写清楚。
- **breakdown-v3**：所有非演示请求都用。
  - 在 v2 的规则之上，加一段始终生效的【镜头变化】：景别层次、角度理由、运动、人物动作写进字段、三分构图、视线和主观镜头、镜头的选择。
  - 词表加入新的姿势、道具和环境。
  - 难度规则沿用 v2。
  - 演示模式仍用 v1，因为它只回放录好的输出。旧草稿保留各自记录的版本。
- **精修一轮**：
  - structuredCall 新增可选参数 `refine(value)`，返回修改意见；
  - 校验通过且意见不为空、还有外发次数时，再问一轮；新结果校验通过并且 score 更好才采用，否则保留原结果；
  - 每步最多 3 次外发不变，最多精修一轮；
  - breakdown 只在 `severe` 时精修，演示模式不精修。
- **润色**：
  - polish-v2 的词表加入新枚举；
  - vary 方式把所选镜头当成一段来调；
  - vary 的结果附带变化检查的 warning。
- breakdown 草稿的 issues 里附上变化检查的 warning，现有界面会显示。

## 7 W 线：前端与重排

- 服务器：
  - `relayoutBoards`：对每个未归档镜头，最新一版不是手改，且 renderer_version 不是当前版本时，排一版新的。
  - 手改过的跳过、已是当前版本的跳过，分别计数。
  - 写在事务里，不改动 AI 重绘行。
  - 有测试。
- 分镜页：有可重排的分镜时，显示「用新画法重排 N 个分镜（手改过的不动）」按钮，可以按场次或全部。
- 分镜编辑器：选中人物时有「换个动作」，循环 gesture；姿势下拉里有新姿势。
- 润色对话框里可以选「丰富变化」；拆镜草稿的变化提示清楚可见。
- 图片缓存的 key 加上 PICTURE_VERSION。
- 测试：web 单测，加一个 e2e（s4c-boards）。
