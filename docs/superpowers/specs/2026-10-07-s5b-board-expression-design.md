# S5b 分镜图表现力：情绪与光影（设计）

日期：2026-10-07。版本：S5b（S5 下的中版本，npm 0.11.0）。用户要求：「进一步开发分镜图功能，继续提升其表现力（情感）」。原路线图的「镜头拍摄提示」「拍摄日简报」顺延为 S5c、S5d。

## 0 现状与问题

看 `npm run look` 的 12 个标准镜头和 12 个变化镜头（S4c）：

- 人物的脸永远是同一个表情：眼睛是一道弧加一个小竖点，嘴是一条横线。台词再激烈，分镜上的人也没有情绪。
- 身体只有姿势和手势，没有情绪带来的姿态（垂头、耸肩、前倾、后仰）。
- 所有镜头都是同一种白天的光：剧本写「夜」「黄昏」的场次，分镜看起来和白天一样。
- 造型细节：上臂顶端的圆头露在肩线外面，像垫肩；头发是一整块深色，像头盔；眼睛没有瞳孔，看不出往哪里看。

## 1 目标

1. **情绪**：每个人物可以有一种情绪：平静、开心、难过、生气、害怕、吃惊、紧张（7 种）。
   - 脸：眉、眼、嘴随情绪变化，近景和特写才画得出的细节（瞳孔、泪痕）按头的大小决定是否画出。
   - 身体：难过时垂头、含胸，生气时上身前倾，害怕时耸肩、后缩，吃惊时后仰，开心时挺胸、歪头，紧张时耸肩。
2. **情绪从哪里来**，按优先级：
   1. 用户在镜头编辑器或分镜检查器里选的；
   2. AI 拆镜或润色写的 `emotion`；
   3. 都没有时，从镜头的「画面」（action）文字里读：「小林推门进来，看见信，愣住了」→ 小林吃惊。不用 key。
3. **时段光影**：场次标题里的时间（日、夜、黄昏……）决定这一格的光：
   - 日：和现在一样；
   - 黄昏（含清晨）：太阳很低，从侧面照来，影子拉长，天空上半部压暗；
   - 夜：整格变暗，人物周围留一圈光（像被路灯、台灯照着），脸保持亮，窗户是黑的。
   - 检查器可以改这一格的时段。
4. **造型细节**：上臂收进肩线，不再像垫肩；头发加几道发丝，不再像头盔；眼睛有瞳孔。

不做：彩色、真实光源的物理光照、口型、表情动画、按台词判断情绪（台词是谁说的不确定）。

## 2 契约（lead）

- `shot.ts`：
  - `Emotion = z.enum(['neutral','happy','sad','angry','afraid','surprised','tense'])`；
  - `ShotSubject.emotion: Emotion.nullable().optional()`：不填或 null 表示「按画面文字推断」。
- `board.ts`：
  - `BoardSubject.emotion: Emotion.nullable().optional()`：不填或 null 画平静的脸；
  - `TimeOfDay = z.enum(['day','dusk','night'])`；
  - `BoardScene.time: TimeOfDay.optional()`：不填等于 day。
- `LayoutContext.time_label?: string | null`：服务端从镜头所在场次的 `time_label` 读出。

## 3 不变量

- **哈希不变**：
  - `shotContentHash`：subject 的 emotion 为 null 或缺省时不进哈希（和 camera_notes 同理），S5b 之前的镜头哈希不变，分镜不会因此被标成过期。
  - `structureHash`：subject 的 emotion 为 null 或缺省、scene.time 缺省或为 `day` 时都不进哈希。S4c 固定的 4 个 spec 的哈希保持不变（`s4c-structure-hash` 测试），已采用的 AI 重绘不会被标成「结构已变」。
- `RENDERER_VERSION` 改为 `board-s5b`，`PICTURE_VERSION` 改为 `picture-s5b`。分镜页的「用新画法重排」会对没手改过的旧分镜重排一版，带上推断出的情绪和场次时段。
- 确定性：同一份 spec 逐字节一致；随机量一律 `rngFor(seed, key)`。core 保持纯函数。
- SVG 只用表现属性，只用灰色。
- 画风指标 L1–L7 仍对 12 个标准镜头（白天）断言。夜景和黄昏另做渲染检查，不套 L4（前中远景亮度递增在夜景里不成立）。
- 性能：单格 pencil 生成 < 150 ms，1840 px PNG < 1.5 s。
- 洁净室：示例和测试里的人名都是虚构的。

## 4 情绪推断（core `board/emotion.ts`，纯函数）

`inferEmotions(text, people: { alias, label }[]): Map<alias, Emotion>`

- 关键词表，长词优先：
  - 开心：笑、微笑、大笑、开心、高兴、兴奋、得意、欣喜、欢呼；
  - 难过：哭、流泪、泪、难过、伤心、悲、失落、沮丧、哽咽、抽泣、叹气、苦笑；
  - 生气：怒、生气、愤怒、吼、咆哮、瞪、骂、拍桌、摔、冷笑；
  - 害怕：害怕、怕、恐惧、惊恐、发抖、颤抖、后退、退后、躲；
  - 吃惊：吃惊、惊讶、震惊、愣住、愣、目瞪口呆、惊；
  - 紧张：紧张、不安、焦急、犹豫、皱眉、担心、忐忑、屏住呼吸、咬唇。
- 否定：词前紧挨「不、没、别、未、忍住」时跳过这个词，「忍住眼泪」这类仍算难过。
- 归属：按「。！？；，、\n」切成小句。
  - 小句里提到人物名字（roster 的 label）时，情绪归第一个提到的人；
  - 没提到名字的小句，沿用上一个提到的人（中文常省略主语）；
  - 整段都没有名字、镜头里只有一个人时，归这个人。
- 同一个人有多个情绪时取最后一个：镜头通常停在反应上。
- 只读 `action`；`action` 里读不出时再读 `narrative_purpose`。台词不读。

layout：`BoardSubject.emotion = shot.subjects[i].emotion ?? inferred.get(alias) ?? null`，平静不写。

## 5 脸和身体（core `puppets.ts`）

`BuildPuppetOptions.emotion?: Emotion`。

- **脸**（`FACE` 表，每种情绪给出眉、眼、瞳孔、嘴的参数）：

  | 情绪 | 眉 | 眼 | 嘴 | 其他 |
  |---|---|---|---|---|
  | 平静 | 平 | 上眼睑弧线加瞳孔 | 横线 | |
  | 开心 | 略抬 | 弯成 ∩ 形，不画瞳孔 | 嘴角上扬 | |
  | 难过 | 内端上挑 | 眼睑下垂，瞳孔偏下 | 嘴角下垂 | 近景画一道泪痕 |
  | 生气 | 内端压低，成 V 形 | 眯起 | 紧闭、略下弯 | |
  | 害怕 | 抬高，内端上挑 | 睁大的整圈眼眶加小瞳孔 | 小而张开 | |
  | 吃惊 | 高高抬起 | 睁大的整圈眼眶加小瞳孔 | 张成 O 形 | |
  | 紧张 | 微皱 | 眼睑略低 | 短而紧 | |

- 瞳孔和张开的嘴是**实心小形**：`PuppetLine.closed = true`。铅笔里画成填充（亮部用墨色，暗部用纸色），结构稿里画成填充。只有整圈都朝向镜头时才画成闭合形，否则退成线。
- 「难过」低头：五官整体下移 0.1 个头高。
- **身体**（在 `joints3` 之后按情绪改关节，跑和躺只改脸）：
  - 前倾或后仰：骨盆以上的关节绕骨盆在前后方向转一个角度（生气 +8°，难过 +6°，吃惊 −6°，害怕 −5°）；
  - 耸肩：肩抬高，肘、腕、手跟着抬 60%（害怕 0.018，紧张 0.01，生气 0.006）；
  - 垂头：头下沉、前移（难过）；
  - 歪头：开心 5°，害怕 −3°，叠加在手势的歪头上。
- **造型**：
  - 上臂起点沿手臂下移、起点半径收窄，圆头收进肩线；
  - 头发在发帽上加 3–5 道发丝（`hair` 类细线，深色头发上用纸色）；
  - 瞳孔见上表。

## 6 时段光影

- core `timeOfDay(label)`：
  - 夜、晚、晚上、夜晚、深夜、午夜、凌晨、夜间、雨夜、雪夜、夜景、NIGHT → night；
  - 黄昏、傍晚、日落、昏、清晨、黎明、拂晓、日出、晨、DUSK、DAWN、EVENING → dusk；
  - 其余（含没有时间）→ day。
- layout：`scene.time` 只在不是 day 时写入。光的方向：
  - 日：方位 45°、高度 40°，不变；
  - 黄昏：方位 70°、高度 14°（侧逆光，影子长）；
  - 夜：方位 30°、高度 55°（主光从上方照人物）。
- pencil：
  - **夜**：
    - 整格铺一层暗调（tone 2.4，进排线蒙版，所以有交叉排线）；
    - 主要人物的上半身周围有一圈径向渐变的亮区（光池，半径约人物高的 0.9 倍），人物照常画在上面；
    - 布景的明暗整体 +1 档；窗玻璃画成暗的；
    - 暗角加重。
  - **黄昏**：
    - 天空（地平线以上）从上往下由 tone 1.4 渐变到 0；
    - 影子随低角度光自然拉长；
    - 暗角略加重。
- 检查器：「时段」选择（日 / 黄昏 / 夜），改了算手改。

## 7 AI

- breakdown 和 polish 提示词各升一版（breakdown-v4、polish 下一版），在 subjects 的字段说明里加一句：`emotion` 是这个镜头里人物的情绪，从七种里选，看不出来写 null。
- 归一化表：开心、高兴、喜悦 → happy；难过、悲伤、伤心 → sad；生气、愤怒 → angry；害怕、恐惧 → afraid；吃惊、惊讶、震惊 → surprised；紧张、不安、焦虑 → tense；平静、中性、无 → neutral。不认识的值交给 zod 报错，进修复轮。
- 演示回放的录音没有 emotion，照样通过（字段可选），由画面文字推断。

## 8 前端

- 标签：情绪（平静、开心、难过、生气、害怕、吃惊、紧张），时段（日、黄昏、夜）。
- 镜头编辑器的人物行：加「情绪」选择，第一项是「自动（按画面描写）」。
- 分镜检查器：
  - 选中人物时有「情绪」选择；
  - 场景部分有「时段」选择。
- 润色对比和草案对比里，人物的摘要带上情绪。

## 9 测试

- core：
  - 推断（归属、省略主语、否定、长词优先、取最后一个、只有一人时）；
  - `timeOfDay` 映射；
  - 每种情绪的五官都不同，闭合形只在完全朝向镜头时出现；
  - 姿态改动不影响跑和躺；
  - layout 带出情绪和时段；
  - 哈希：内容哈希和 structureHash 对不填、null 都不变；
  - L1–L7 仍过；夜景整格平均亮度明显低于同一镜头的白天版；确定性；性能。
- server：
  - 夜场的镜头排出的分镜带 `time: 'night'`；
  - 镜头的 emotion 进分镜；
  - 旧 renderer 的分镜可以重排。
- web：标签与摘要。
- e2e：在镜头编辑器把情绪改成「生气」，分镜页的检查器显示「生气」。
- look：变化镜头新增夜景街道、黄昏野外、夜景室内三格；新增 `expressions.png`，7 种情绪 × 正面和 3/4 侧面，特写。
